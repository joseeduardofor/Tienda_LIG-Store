# Tienda_LIG-Store
Tienda online SPA con HTML, CSS y JavaScript vanilla. Consume la API pública de FakeStoreAPI para mostrar un catálogo dinámico de productos con imágenes, precios y categorías. Incluye carrito de compras persistente con localStorage, modal de detalle de producto, pasarela de pago simulada con validación de tarjeta, y generación de ticker
